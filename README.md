# 交付物链接操作

交付物悬停菜单的主机端：为对话中的文件链接执行打开、打开所在文件夹、复制文件和复制完整路径操作。

Host half of the Deliverable Hover Menu: performs open, reveal, copy-file and copy-path actions for conversation file links.

## 安装

**方式一（推荐）**：在 DSH 插件的「发现」页添加索引源

```
https://raw.githubusercontent.com/abcrabbit/dsh-plugin-index/main/index.json
```

然后搜索并安装本插件。

**方式二（手动）**：下载本仓库，在 DSH「设置 → 插件 → 添加插件 → 本地目录」中选择本目录。

## 兼容性

- DSH 0.2.2 系列（在 `0.2.2-rc.5` 上验证）
